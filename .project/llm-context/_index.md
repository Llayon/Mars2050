# LLM Context Index — Mars2050

Быстрое оглавление контекстов для агентов. Читай только нужный файл.

## Структура контекстов

| Файл | Описание | Когда читать |
|------|----------|--------------|
| `architecture.md` | Правила архитектуры, лимиты, паттерны | Перед любым изменением кода |
| `building.md` | Домен зданий (типы, конфиги, сервисы) | Работа со зданиями |
| `resource.md` | Домен ресурсов (типы, формулы) | Работа с ресурсами |
| `map.md` | Домен карты (генерация, исследование) | Работа с картой |
| `colony.md` | Домен колоний | Работа с колониями |
| `pvp.md` | Домен PvP (атака, торговля) | Работа с PvP |
| `combat.md` | Тиковая симуляция боя | Работа с battle engine, targeting, movement, replay |
| `auth.md` | Домен авторизации | Работа с auth |
| `ui.md` | HUD, overlays, desktop/TWA screens | Работа с игровым UI |
| `events.md` | События колонии и modifiers | Работа с events |
| `leaderboard.md` | Рейтинг колоний | Работа с leaderboard |

## Быстрый старт

1. Прочти `architecture.md` (обязательно перед правками)
2. Прочти нужный доменный файл
3. Используй `LLM-CONTEXT.md` для общего понимания проекта
