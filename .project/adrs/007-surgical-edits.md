# Decision: Surgical Edits Only

## Context
ИИ-агенты часто переписывают файлы целиком (`write_file`), даже если нужно изменить 1 строку. Это опасно: теряются непрочитанные части кода, ломается история git, сложно ревью.

## Rationale (Критично для ИИ)
**ПОЧЕМУ только точечные правки?**

1. **Сохранение неизвестного**: ИИ не всегда читает ВЕСЬ файл. Перезапись убивает непрочитанный код
2. **Git history**: Surgical edit дает четкий diff, перезапись — огромный diff с непонятными изменениями
3. **Безопасность**: Меньше шансов случайно удалить важный код
4. **ИИ часто хочет "переписать красиво"**:
   - ❌ "Этот файл можно переписать лучше" — опасно, может сломать логику
   - ✅ "Изменим только нужные строки" — безопасно
5. **Инструмент `edit`**: Использует `oldString` → `newString`, меняет только указанный фрагмент

## Decision
- Существующие файлы: только точечные правки через `edit` (replace exact string)
- Новые файлы: `write` (файл не существует)
- Перед правкой: обязательно прочитать файл (инструмент требует)
- Объем правки: минимальный фрагмент, необходимый для изменения

## Good Example (Самое важное для ИИ)
```typescript
// ✅ ПРАВИЛЬНО: Surgical edit (замена фрагмента)
// Было:
function calculateCost(building: Building) {
  return BUILDING_TYPES[building.type].cost
}

// Стало (через edit tool):
// oldString: "return BUILDING_TYPES[building.type].cost"
// newString: "return calculateBuildingCost(building.type)"

// Только 1 строка изменена, остальное нетронуто
```

```typescript
// ✅ ПРАВИЛЬНО: Чтение перед правкой
// 1. Read file
// 2. Edit specific fragment
// 3. Verify changes
```

## Bad Example (Самое важное для ИИ)
```typescript
// ❌ НЕПРАВИЛЬНО: Перезапись всего файла (ИИ может захотеть "упростить")
// Использование write_file на существующем файле — ЗАПРЕЩЕНО!
// Потеряется код, который ИИ не прочитала
```

```typescript
// ❌ НЕПРАВИЛЬНО: "Рефакторинг" всего файла
// "Давайте переименуем все переменные для единообразия"
// Опасно: можно сломать логику, огромный diff
// Делайте только необходимые изменения
```

```typescript
// ❌ НЕПРАВИЛЬНО: Не читая файл, пытаться его изменить
// Edit tool выдаст ошибку "You must read the file first"
// Это сделано специально для безопасности
```

## Consequences
### Positive
- ✅ Безопасность: не теряем непрочитанный код
- ✅ Git history: четкие, маленькие diff-ы
- ✅ Легкое ревью: понятно, что именно изменилось
- ✅ Меньше регрессий: не ломаем соседний код

### Negative
- ⚠️ Нужно точно попадать в `oldString` (с учетом отступов)
- ⚠️ При конфликтах (multiple matches) нужно читать файл заново
