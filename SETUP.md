# Настройка Mars2050

## 1. Создание проекта Supabase

1. Перейди на [supabase.com](https://supabase.com) и создай новый проект
2. Запиши URL проекта и anon key

## 2. Настройка переменных окружения

Отредактируй файл `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

## 3. Создание базы данных

В SQL Editor на Supabase выполни скрипт `supabase-schema.sql`

## 4. Запуск игры

```bash
npm run dev
```

Открой http://localhost:3000

## Структура игры

- **Ресурсы**: кислород, вода, энергия, минералы, еда, очки исследования
- **Здания**: 6 типов зданий с разными характеристиками
- **Карта**: 50 локаций на Марсе (равнины, горы, каньоны, кратеры, ледники)
- **PvP**: атаки на колонии, торговля, рейтинг

## Функционал

✅ Экономика (ресурсы, добыча, потребление)
✅ Строительство зданий
✅ Исследование карты
✅ PvP (атаки, торговля)
✅ Рейтинг игроков
