# Combat-core: шаблон журнала выполнения

Это незаполненный шаблон, не отчёт о выполнении. При запуске создать из него `docs/combat-core-progress.md`; существующий журнал не перезаписывать. Значения `не задано` и `NOT_RUN` заменять только фактическими данными. Связанные требования: [план](combat-core-extraction-plan.md) и [промпт](combat-core-agent-prompt.md).

## Этапы

Статусы: `pending`, `implementing`, `verifying`, `needs_revision`, `needs_external_review`, `accepted`, `blocked`, `stopped_budget`. E2–E4 разбивать на отдельные строки срезов; общий этап не принимать по одному успешному примеру. B1 находится внутри этого разбиения, а не после полной E4.

| Этап/срез | Зависимости | Статус | Проверенный snapshot / evidence / reviewer |
| --- | --- | --- | --- |
| E0 | Нет | `pending` | Нет |
| E1 | E0 | `pending` | Нет |
| E2–E4: срезы по аудиту | E1 и уточнённый граф | `pending` | Нет |
| B1: автономный бой | Минимальные срезы по E0 | `pending` | Нет |
| Ранний summon | B1 / spawn-срез | `pending` | Нет |
| E5 | Принятые необходимые срезы | `pending` | Нет |
| E6 | Принятые необходимые срезы и перенос B1 | `pending` | Нет |
| E7 | E2–E6, B1 | `pending` | Нет |

## Текущий цикл

- Срез / номер попытки / цель: не задано.
- Принятые зависимости и критерии приёмки: не задано.
- Исполнитель / разрешённые файлы / запреты: не задано.
- Snapshot до запуска тестов: чистый commit либо HEAD + хеш staged/unstaged diff в формате `git diff --binary` + manifest untracked-файлов с хешами; не задано.
- Путь к manifest и логам без секретов: не задано.
- Запись исходников приостановлена; snapshot после команд совпадает: не подтверждено.
- Хеш архива и результат внешнего потребителя для package-check: не задано.
- Активные процессы, cwd, session/PID и результат последней проверки: не проверено.

## Выполненные команды

Не копировать `PASS` из старого запуска. Добавлять отдельные строки для baseline, новой версии, специализированных тестов, build, archive consumer и portability. Отсутствие команды или окружения отмечать `NOT_RUN`/`BLOCKED`.

| UTC / snapshot | Команда / cwd / окружение | Exit code | Статус | Лог / результат |
| --- | --- | --- | --- | --- |
| Не задано | Обязательные проверки ещё не запускались | Нет | `NOT_RUN` | Нет |

## Независимое ревью

- Reviewer / отдельная сессия / UTC: не задано.
- Проверенные критерии и snapshot: не задано.
- Вердикт: `NOT_RUN`; без отдельного ревью — `needs_external_review`, не `PASS`.
- Для повторного итогового ревью после изменений: новая сессия и новый snapshot.

| ID замечания | Критерий / файл / доказательство | Исправление / проверка | Статус |
| --- | --- | --- | --- |
| Не задано | Ревью ещё не выполнялось | Нет | `NOT_RUN` |

## Решения, блокеры и восстановление

- Новые подтверждённые факты последней попытки: нет.
- Последовательных попыток без прогресса: 0; эскалация после 3 по протоколу.
- Открытые blockers / проверенные гипотезы / необходимое решение: не проверено.
- Одобренные пользователем изменения scope/полномочий/бюджета: нет.
- Последний принятый checkpoint / соответствие итогового commit проверенному snapshot: нет.
- Устаревшие проверки после изменений / что повторить: не проверено.
- Следующий точный шаг: проверить окружение и начать E0.

## Итог запуска

- Статус: `not_started`; итоговые варианты — `completed`, `blocked`, `needs_external_review`, `stopped_budget`.
- Реально принятые этапы и коммиты: нет.
- Незавершённые критерии / невыполненные проверки / риски: реализация не начата.
- Финальная интеграционная проверка и независимое ревью: `NOT_RUN`.
- Разрешённые и фактически выполненные внешние действия: нет.
- Что нужно следующей сессии или пользователю: не задано.
