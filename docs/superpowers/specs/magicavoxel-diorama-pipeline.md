# Voxel Diarama Pipeline — MagicaVoxel Reference

Source: Video tutorial — последовательность создания воксельной диорамы в MagicaVoxel.
Approach: modular asset creation → scene assembly (Lego-style).

## Часть 1: Создание воксельных ассетов

### 1. Тайл "Земля с травой" (10×10×10)

**Палитра:**
| Color | Name | HEX |
|-------|------|-----|
| 1 | Базовая земля | `#8B5A2B` |
| 2 | Тёмная земля | `#5C3A21` |
| 3 | Светлая земля | `#A07245` |
| 4 | Базовая трава | `#4CAF50` |
| 5 | Блик травы | `#81C784` |
| 6 | Тень травы | `#388E3C` |

**Шаги:**
1. Box (Attach) → Color 1 → заполнить весь 10×10×10
2. Paint (заливка по плоскости) → Color 4 → клик по верхней грани (Z=9)
3. Voxel (Paint) → Color 2 → прерывистые линии на боковых гранях (Z 0–4)
4. Voxel (Paint) → Color 3 → редкие вкрапления (Z 3–6)
5. Voxel (Paint) → Color 4 → неравномерная "бахрома" на боках (Z 7–8, зубчики 1–3 вокселя)
6. Voxel (Paint) → Color 5 → ~15% вокселей на верхней плоскости + 2–3 на бахроме
7. Voxel (Paint) → Color 6 → ~10% на верхней плоскости + в углублениях бахромы

### 2. Тайлы "Вода и Водопад"

**Дополнительно в палитру:**
| Color | Name | HEX |
|-------|------|-----|
| 7 | Базовая вода | `#2196F3` |
| 8 | Светлая вода / Рябь | `#64B5F6` |
| 9 | Пена / Блики | `#FFFFFF` |

**Горизонтальная вода (10×10×10):**
1. Box (Attach) → Color 7 → заполнить весь куб
2. Voxel (Paint) → Color 8 → 4–6 коротких линий по X на Z=9 (вектор течения)
3. Voxel (Paint) → Color 9 → 2–3 блика рядом с линиями

**Вертикальный водопад (10×10×20):**
1. Box (Attach) → Color 7 → заполнить весь 10×10×20
2. Voxel (Paint) → Color 8 → 3–5 прерывистых вертикальных линий по лицевой грани
3. Voxel (Paint) → Color 9 → вертикальные полосы пены, сгущение внизу (Z 0–5)

### 3. Растительность (деревья, кусты, цветы)

**Дополнительно в палитру:**
| Color | Name | HEX |
|-------|------|-----|
| 10 | Ствол дерева | `#5D4037` |
| 11 | Тень ствола | `#3E2723` |
| 12 | Базовая листва | `#43A047` |
| 13 | Блик листвы | `#66BB6A` |
| 14 | Тень листвы | `#1B5E20` |
| 15 | Красный цветок | `#F44336` |
| 16 | Жёлтый цветок | `#FFEB3B` |
| 17 | Белый цветок | `#FFFFFF` |
| 18 | Стебель цветка | `#8BC34A` |

**Дерево (10×10×20):**
1. Box (Attach) → Color 10 → столб 2×2×10 (X=4–5, Y=4–5, Z=0–10)
2. Voxel (Paint) → Color 11 → вертикальные линии коры
3. Box (Attach) → Color 12 → нижний ярус 6×6 или 8×8 (Z=6–9)
4. Erase → скруглить углы нижнего яруса
5. Box (Attach) → Color 12 → средний ярус 4×4 (Z=10–13)
6. Box (Attach) → Color 12 → верхушка 2×2 (Z=14–16)
7. Voxel (Paint) → Color 13 → блики 10–15%
8. Voxel (Paint) → Color 14 → тени 10% в углублениях

**Куст (5×5×5):**
1. Box (Attach) → Color 12 → 3×3×3 или 4×4×3
2. Erase → скруглить верхние углы (полусфера)
3. Voxel (Paint) → Color 13 (блики) + Color 14 (тени к основанию)

**Цветы (5×5×5):**
1. Voxel (Attach) → Color 18 → стебель 1–2 вокселя
2. Voxel (Paint) → Color 15/16/17 → бутон 1–4 вокселя

### 4. Деревянные элементы (мосты, лестницы, заборы) — 10×10×10

**Палитра:**
| Color | Name | HEX |
|-------|------|-----|
| 19 | Светлое дерево / доски | `#D7CCC8` |
| 20 | Тень / окантовка | `#8D6E63` |
| 21 | Тёмное дерево / опоры | `#5D4037` |

**Лестница:**
1. Box (Attach) → Color 19 → ступенька 3×6×1
2. Voxel (Paint) → Color 20 → обводка нижнего контура
3. Копировать + сдвиг на +1Z +2X → 3–4 ступени

**Мостик:**
1. Box (Attach) → Color 19 → платформа 4×12×1
2. Voxel (Erase) → прорези через каждые 2 вокселя (отдельные доски)
3. Line → Color 21 → две балки-опоры под досками
4. Voxel (Attach) → Color 21 → столбики 3–4 вокселя по краям
5. Line → Color 21 → горизонтальные перила

### 5. Камни (8×8×8)

**Палитра:**
| Color | Name | HEX |
|-------|------|-----|
| 22 | Базовый камень | `#9E9E9E` |
| 23 | Светлый камень / блики | `#BDBDBD` |
| 24 | Тёмный камень / тени | `#757575` |

1. Box (Attach) → Color 22 → блок 4×5×4 или 3×3×2
2. Voxel (Erase) → стесать углы и грани (без симметрии)
3. Voxel (Paint) → Color 23 → выступающие грани и верх
4. Voxel (Paint) → Color 24 → нижние грани и углубления
5. Создать вариации: плоский, крошечный 2×2 (галька)

### 6. Сундук (8×8×8)

**Палитра:**
| Color | Name | HEX |
|-------|------|-----|
| 25 | Основа (золотое дерево) | `#F57C00` |
| 26 | Металлическая окантовка | `#3E2723` |
| 27 | Замок | `#FFC107` |
| 28 | Щель крышки | `#212121` |

1. Box (Attach) → Color 25 → корпус 6×4×3
2. Box (Attach) → Color 25 → крышка 6×4×1 сверху + полоса 6×2×1
3. Voxel/Line (Paint) → Color 26 → все 12 рёбер + поперечные полосы на крышке
4. Voxel (Paint) → Color 28 → линия стыка на Z=3
5. Voxel (Paint/Attach) → Color 27 → замок 1–2 вокселя по центру передней грани

### 7. Облака (12×12×8)

1. Box (Attach) → Color 9 (белый) → фундамент 6×4×1
2. Voxel (Attach) → хаотичные полусферы по верху и бокам (дно плоское)
3. Создать вариации: длинное/узкое, маленькое/круглое

## Часть 2: Сборка диорамы "Парящий остров"

### 8. Базовый ландшафт (126×126×126)
1. World mode → расставить тайлы земли платформой 8×10 (округлая форма)
2. Средний ярус 6×6 со смещением
3. Верхний ярус (гора) 3×3 на краю
4. Перевернуть камеру → сталактиты вниз (сужающиеся конусы)

### 9. Русло водопада
1. Заменить 2–3 тайла на вершине на горизонтальную воду
2. На краю — вертикальный водопад
3. У подножия — бассейн из горизонтальной воды
4. Повторить каскады до нижнего яруса
5. Главный водопад в пустоту с края острова

### 10. Мосты и лестницы
- Лестницы между ярусами (врезать в ландшафт)
- Мостики через ручьи и бассейны

### 11. Декорирование
- 4–6 деревьев, группы по 2–3, избегать симметрии
- Камни по берегам ручьёв и у подножий
- Кусты и цветы группами (не перебарщивать)

### 12. Главный объект
- Сундук на вершине горы, рядом с истоком водопада, лицом к зрителю

### 13. Финальные штрихи
- 1–2 малых парящих острова (сателлиты) с деревом/камнем
- Облака на разной высоте вокруг острова

### 14. Рендер
- Render tab → Orthographic или 45° перспектива
- Sun под 60°, мягкие тени
- Дождаться Accumulation → сохранить
